# UI 规范

本文档是 Math Tools 全项目唯一的 UI 风格规范。视觉取值以 `src/styles/tokens.css` 为准，本文档说明风格定位与使用规则。新增或修改界面时先读本文件；改动视觉令牌时同步更新本文件。

## 风格定位：简洁课堂风

- **使用场景优先**：16:9 投影与教学大屏，教师远距离操作，学生远距离观看。可读性永远优先于装饰。
- **白底深色字**：明亮教室投影下对比最稳。页面背景用极浅蓝灰 `--color-bg`，内容承载在白色 `--color-surface` 卡片上，层次靠留白与轻阴影，不靠多彩色块。
- **一个主色**：深蓝 `--color-primary`（#2563EB）只标记两件事——可操作的元素（按钮、链接、可拖动的点）和当前关键数值。页面出现大片蓝色即视为越界。
- **圆角与轻阴影**：圆角 `--radius`（12px）传达亲切感，阴影仅用于分层（卡片静止 `--shadow-card`、浮层 `--shadow-pop`），不做渐变与发光。

## 色彩令牌

| 令牌 | 取值 | 用途 |
| --- | --- | --- |
| `--color-bg` | #F6F8FB | 页面背景 |
| `--color-surface` | #FFFFFF | 卡片、控制栏、对话框 |
| `--color-text` | #111827 | 正文与标题 |
| `--color-text-secondary` | #4B5563 | 次要文字、刻度标签 |
| `--color-primary` | #2563EB | 可操作元素、关键数值 |
| `--color-primary-hover` / `--color-primary-active` | #1D4ED8 / #1E40AF | 主色交互态 |
| `--color-primary-soft` | #EFF4FF | 标签、提示条等浅蓝底 |
| `--color-border` | #D8DFE9 | 边框与分隔 |
| `--color-focus` | #F59E0B | 键盘焦点环（与主色明确区分） |
| `--color-danger` / `--color-danger-soft` | #B91C1C / #FEF2F2 | 错误与破坏性操作 |
| `--color-axis` | #334155 | 数学图形的轴线等中性深色 |

规则：

- 不引入令牌表之外的颜色。案例的数学语义色在案例目录内定义，且必须配合文字或形状，不得单独依赖颜色传达数学含义。
- 焦点环只用琥珀色，与主色蓝保持距离，任何背景下可辨。

## 字号与间距

- 字号四档：`--font-size-sm` 16px（辅助）、`--font-size-body` 20px（正文与控件）、`--font-size-lg` 24px（小节标题、演示页标题）、`--font-size-title` 36px（页面标题）。不新增字号档。
- 间距用 4px 基数的 `--space-1` 到 `--space-8` 令牌，不写散落的像素值。
- 触控目标不小于 `--touch-target`（48px），指针、触控、键盘等效可达。

## 组件规则

- **按钮**：默认次级（白底描边）；一个视图最多一个主操作用 `.primary`（实心蓝底白字）。hover 加深，`:focus-visible` 显示焦点环。
- **卡片**：白底 + `--radius-lg` + `--shadow-card`，hover 升到 `--shadow-pop`。
- **标签**：浅蓝底胶囊（`--color-primary-soft` + `--color-primary-active` 文字），只用于分类信息。
- **提示条**：浅蓝底 + 左侧 4px 主色条（`.notice`），用于参数修复等可 dismiss 的提示。
- **演示控制栏**：贴底、白底、上边框 + 上投影，左侧案例标题，右侧操作按钮；可折叠为右下角悬浮按钮。
- **对话框**：圆角 `--radius-lg` + `--shadow-pop`，半透明深蓝遮罩。

## 动效

- 只用 120–150ms 的颜色/阴影过渡，服务于状态反馈；不做装饰性动画。
- 遵守 `prefers-reduced-motion`：过渡压缩到近乎即时。

## 可访问性底线

- 正文与背景对比度满足课堂远距离阅读；交互元素有可见 hover 与焦点态。
- 数学含义不以颜色为唯一载体（配合数值文字、形状或标签）。
- 关键操作同时支持指针、触控、键盘。

## 变更流程

视觉变化影响稳定关键场景时，更新对应的 Playwright 截图基线（`pnpm test:e2e -- --update-snapshots`，基线按操作系统生成，需在 macOS 上更新），并在提交信息中说明视觉意图。
