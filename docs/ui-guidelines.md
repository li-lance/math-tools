# UI 规范：温暖课堂工作台

Math Tools 的界面面向教师备课和小学课堂演示。视觉方向是纸张、墨蓝与珊瑚色组成的现代教具：亲切、清楚、安静。本文是风格与页面使用规则的权威文档；token 契约见 [Design Token 规范](design-tokens.md)，实际取值以 [tokens.css](../src/styles/tokens.css) 为准。

## 设计原则

- 数学内容占据视觉中心。界面装饰不能暗示错误的数学关系。
- 使用明亮纸色背景与接近白色的内容面，保留投影上的深色文字对比。
- 墨蓝承载品牌、标题和数学结构；珊瑚色标记操作与当前关键数值。
- 不使用远程字体、外部图片或 CDN 图标。系统字体、内联 SVG 与本地资源支持未来离线使用。
- 装饰图形仅用于案例卡片、预览和案例库介绍区；实际数学舞台保持中性。
- 首版不增加暗色模式。设备的深色偏好不改变用于课堂投影的固定浅色主题。

## Token 分层

| 层级 | 命名 | 职责 |
| --- | --- | --- |
| 基础色 | `--palette-*` | 纸张、墨蓝、珊瑚和辅助教具色 |
| 语义色 | `--color-*` | 页面、内容面、文字、主操作、焦点、错误、数学轴线 |
| 排版与布局 | `--font-*`、`--space-*`、`--radius-*` | 字体、字号、4px 间距系列和组件圆角 |
| 组件与反馈 | `--control-*`、`--card-*`、`--stage-*` | 控件状态、组件形状、表面与反馈 |
| 教具与尺寸 | `--viz-*`、`--size-*` | 二维描边、三维材质、网格、灯光与尺寸角色 |

应用组件优先消费语义 token，不直接填写颜色。新增视觉值先判断是否已有相同语义，再扩展 token，避免给每个页面复制一套变量。布局比例、SVG 数学坐标、媒体查询断点和隐藏辅助文字的几何值不属于品牌 token。

Three.js 面色也由设计 token 管理：通用教具色经 `--viz-3d-face-*` 映射到案例的固定面身份。案例只保存映射，不复制色值；材质透明度、棱线、网格和灯光通过类型化接口读取同一 CSS 来源。token 不改变面的数学对应关系，也不以 UI 主色替换每一个面。

## 色彩角色

- `--color-bg`：课堂纸色；`--color-surface`：卡片、控件和对话框；`--color-stage`：数学舞台。
- `--color-text` 与 `--color-text-secondary`：墨蓝标题和蓝灰正文。
- `--color-accent`：亮珊瑚装饰；`--color-primary`：更深的操作珊瑚，承载白色按钮文字及关键数值。亮珊瑚不直接用作白字按钮底色。
- `--color-primary-hover` 和 `--color-primary-active`：递进加深的操作态。
- `--color-focus`：紫色焦点环。不能用阴影替代键盘焦点。
- `--color-danger`：错误信息；`--color-primary-soft`：普通提示，不能冒充错误。
- 卡片数学预览使用蓝灰或浅杏色底与墨蓝线条，并始终附带案例名称。颜色不承担唯一分类信息。

正文、辅助文字和按钮文字以至少 4.5:1 为对比目标；大字与交互图形至少 3:1。颜色对比检查不能替代真实投影可读性评审。

## 排版与空间

正文为 18px，辅助文字为 16px；小节标题 24px，页面标题 32–44px，案例库主标题 36–60px，随视口变化。正文行高 1.7，标题行高 1.25。默认使用系统中文黑体；标题以本地圆体优先，不依赖它必然存在。数学数字使用等宽数字排版，SVG 字号以实际课堂视口检查为准。

间距遵循 4px 基数。常用触控目标至少 48px。页面最大宽度 76rem，左右留白随视口变化；900px 和 600px 为统一布局断点。手机保证功能完整、控件可达，不把桌面整页等比缩小。

圆角从输入框、卡片到舞台逐级增大。卡片轻阴影用于分层，浮层使用更明显的阴影。主按钮带少量底部阴影表达可按压，数学对象不加装饰阴影。

## 页面模式

### 案例库

顶部是品牌与案例库导航。介绍区左侧是一句产品主张和说明，右侧是静态数学示意；手机隐藏非必要介绍插图。

案例区包含可访问的搜索、年级和主题筛选，以及实时结果数量。卡片使用大幅静态数学示意、分类、标题、简介和“查看详情”链接。当前只有两个真实案例，不填充虚构卡片或未上线功能。无结果时明确说明并提供“清除筛选”。

### 案例详情

首屏采用数学示意与案例说明双列布局，主操作“进入演示”直接可见。示意标注为案例示意，不伪装成交互画布。

教学目标和操作指引分区呈现，步骤用编号帮助教师快速浏览。教学评审默认折叠，但真实评审状态在折叠时仍可见；展开后保留全部术语、有效性说明和误导风险。手机按预览、说明、教学目标、操作指引的顺序堆叠。

### 演示舞台

纸色外围包围明亮舞台，轻量页头说明课堂模式。底部教具托盘保留案例名、返回、重置、全屏、帮助与收起操作；全屏是该托盘的主操作。折叠后保留一个可触达的恢复按钮。

数学内容、案例参数与外壳动作保持各自原有职责。数轴的坐标映射与正方体折叠逻辑不因视觉重设计而改变。手机上托盘按钮换行，3D 画布保持可操作高度，滑杆标签与输入可换行。

数轴内部坐标随可用宽度调整，拖动点直径至少 48px。可用宽度低于 900px 时保留全部刻度线，只标注区间端点及有足够间距的零点；当前值始终单独显示，避免把完整桌面 SVG 缩成难以辨认的小图。键盘步长与整数吸附保持不变。

三维教具采用半透明结构观察（类似建模工具的 See-through 显示），保留适度透视与有方向的明暗。面使用浅色半透明填充，可见棱用深色实线，被遮挡棱用淡虚线，不能将遮挡棱误表现为缺失棱。深度预绘制只服务棱线分类，不绘制不透明表面。正方体按当前六个面的包围范围自动取景；重置视角只恢复默认观察方向和取景，不改变展开参数。面名称始终对应初始模型，只有未被实体遮挡、且不接近侧向的面才显示标签；结构可以透视，文字不穿透堆叠。

参考网格属于三维世界中的地平面，始终低于当前模型，用低对比度线条和远处淡出提供空间参照，不能冒充尺寸标尺。默认开启，可通过具备 `aria-pressed` 状态的按钮关闭；开关和相机状态不写入分享链接。网格颜色使用 `--color-3d-grid-*`。视角工具放在画布外，避免压住模型和面标签。

## 组件状态

按钮需覆盖默认、悬停、按下、键盘焦点和禁用态。主操作用深珊瑚，次要操作用描边；导航与卡片链接不同时铺满实心主色。所有输入都有可访问名称；占位文字不替代标签。

帮助使用原生 dialog，支持 Escape 关闭与焦点返回。错误恢复、参数修复提示使用中文并沿用已有状态语义。原生 details 承载高级参数与教学评审，保留键盘开合能力。

动效仅用于 140ms 的背景色与阴影反馈，尊重 `prefers-reduced-motion`。不添加自动漂浮、旋转、闪烁或与教学无关的转场。

## 文件与验证

- [tokens.css](../src/styles/tokens.css)：全项目视觉取值。
- [design-tokens.md](design-tokens.md)：分层、单位、状态、读取接口与维护规则。
- [global.css](../src/styles/global.css)：共享控件、页面骨架、品牌与响应式规则。
- `src/components/BrandHeader.tsx` 与 `CaseArtwork.tsx`：导航和静态预览，后者不加载案例运行时。
- 案例 CSS 只描述案例内的布局和数学视觉，引用公共语义 token。

视觉改动需要检查 1600×900 案例库、详情、数轴和正方体场景，并检查 360px 与 768px 的无溢出及关键控件可达性。更新截图基线前先人工查看新图；基线用于记录已审查的布局，不代表教学评审已通过。行为改动运行对应浏览器测试，并执行 typecheck、lint 和单元测试。
